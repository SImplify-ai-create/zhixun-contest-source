# 方案版本说明（v1.1 现行 / S2 模型训练 / S2.1 超参选择 / v2.0 改进 / 备用预案）

> 目的：答辩与评测按**一个主版本**走（v1.1 + S2 + S2.1，v1.0 机制与参数全部保留），
> 改进版与备用预案"做好但默认不开"，官方数据包到手后按本页条件切换。
> 任何切换只动 `config.json`，不改代码。

## v1.0 现行版（默认，当前镜像口径）
> v1.1 在评估口径/调度上的整改见下一节；本表的检测/分档/清洗/调度机制与参数不变。

| 模块 | 机制 |
|------|------|
| 检测（创新点1） | 冻结 PCA 参考编码器 + **MMD²（自校准 3σ）结构路** + **KS（Bonferroni）边际路**，双路与门 |
| 分档（创新点2） | 严重度 = max(残差倍数/3.0, PSI 效应量)，输入侧证据封顶 2.6；`tier_bounds=(1.0, 3.0)` |
| 清洗（创新点3） | 马氏距离选择性清洗；full 档 keep_ratio=0，incremental 档 0.7 |
| 调度（创新点4/5） | 槽位压力预算节流 + 漂移速率自适应窗口（`src/advanced.py`，默认开） |

- 定位：**任何数据上可直接运行、无需标定**，保证"无人工干预跑完、不低于静态基线"两条底线。
- 实测锚点（3 种子，README 同口径）：空流误报 0/90（单路 KS 未校正 28/90）；
  突变末段 0.177±0.030、渐变末段 0.900±0.419（v1.1 留出验收口径）；
  domain 消融 0.170±0.017 vs 恒全量（探针 `runs/probe_accept_gate.csv`）。

## v1.1 整改（2026-11-02，比赛门槛优先）

| 问题 | 旧行为 | 整改 |
|------|--------|------|
| P0 验收失真 | `model.evaluate(X_use)` 在**刚训练过的同一批**上自评，新模型天然占优；回滚判据还拿自评比线上外推 | `gate_mode=holdout`：按时间切最近 20%（`accept_ratio`，最少 30 条）作验收集，训练/验收/回滚同切片比较 |
| P0 初始基线偏乐观 | 初始 RMSE 用训练集自评（0.168） | 折外 5 折估计（`_oof_rmse`），避免 severity 被抬高、收益被虚增 |
| 门槛③ 无锚定 | 静态基线只出现在离线评测 | 冻结 `static_model` 全程并行打点 `vs_static_ratio`；候选在留出集上劣于静态基线+5%（`static_margin`）直接拒绝，并记 `static_anchor_reject` |
| P1 APD 未进生产 | 只在实验臂 A6 | `apd_enabled`：持续报警 ≥`apd_k`(8) 批且残差平坦 ⇒ 抑制重训、不耗预算，最多抑制 6 次；跨窗内聚判据 `_health_check` |
| P1 渐变窗口滞后 | 每 5 批用最近 3 批旧标签混合重训 | `gradual_window=1`（只用最新一批）；`gradual_label_ratio=0.5` 按半量付费，避免第二次漂移前烧光 4000 预算 |
| P1 决策层不可替换 | 决策写死在 `classify` | `src/strategy.py`：`threshold`（默认）/ `rule` / `llm`，LLM 任何异常自动回退规则 |
| P1 软门配额耦合负例 | 旧软门（sigmoid）缩的 `X_use` 同时喂训练+验收+升级判定，quota 缩小→增量没学够→误升级 full→deep seed42 末段 0.161→0.183、多花 799 标注 | `_accept_split` 验收集永远从完整窗口取，与训练切片解耦；软门降级为**仅 incremental 档固定比例 60%（下限 120）**，full 档全量；`config.json` 默认 `soft_quota=true` |
| P2 抗遗忘无度量 | 只回滚"变差"，没记录"忘没忘" | 每次重训记 `retention_ratio`（旧/新模型在初始参考分布上的 RMSE 比，>1 未遗忘）；`retention_rollback=true` 时低于 0.5 自动回滚。**该机制当前未启用（`retention_rollback=false`）：A3 实测未通过，闸门评估已主动否决，见[最终结果表 §11.9](最终结果表.md#119-附录在线抗遗忘闸门的代价评估评估后主动否决2026-11-11)** |

验收证据（`python scripts/probe_accept_gate.py`，3 种子）：留出 vs 自评 → 突变末段
0.177 vs 0.190、渐变 0.900 vs 1.463，标注 1667 vs 1833 / 2167 vs 1900；
同一候选的自评比留出真评乐观 1.5~3.9 倍。APD 在 domain/shallow/deep 12 次运行中
无一次使末段退化，domain seed=7 省 1 次重训、400 条标注。

软门消融（`python scripts/gating_ablation_v11.py`，6 场景 × 2 变体 × 3 种子）：
解耦后 **deep seed42 负例消除**（baseline 与 soft_quota 完全一致 0.161/1800/3）；
**domain seed7 正例增强**（0.197/1800 → 0.153/1180，省 620 标注）；
domain 均值末段 0.187→0.166、标注 1933→1273（-34%）；full 档场景零副作用。
迟滞门端到端零作用，暂缓到官方数据包。

分档打点复核（`python scripts/tier_probe.py`）：留出基线后 domain→incremental、
deep→full、shallow 不触发 cooldown，三档映射仍可分，`tier_bounds=(1.0,3.0)` 无需重调。

## S2 模型训练（2026-11-04，高置信漂移快速恢复 + 证据驱动模型选择 + 标签账本）

| 模块 | 机制 |
|------|------|
| 快速恢复（fast_recovery=a2） | 高置信漂移（双路报警 OR 残差 > 4×基线）时，恢复期 cooldown 从 3 批降到 1 批；a1 模式连续两次报警即触发 |
| 条件模型选择（ConditionalPipeline） | 以 Ridge 起步，full/fast_full 漂移确认后切换 MLP 候选，验收通过永久切换、被拒退回 Ridge——单向不震荡 |
| 标签账本（LabelLedger） | 样本 ID 级计费，重复标签不重复扣费；评分/监控标签默认免费（`eval_labels_free=true`），`acquired == len(paid_ids)` 可审计 |
| Kalman F/Q 缓存 | 状态转移矩阵 F 与过程噪声 Q 从每批 `track()` 重建改为 `_reset()` 时构造一次，长流累计省开销 |
| MLP L2 正则 | `BaselineRegressor` 暴露 `alpha` 参数，配合 S2.1 HPO 调参 |

验收证据（`python scripts/verify_fast_recovery.py`，突变/渐变 × off/a1/a2）：
- fast_recovery 事件在 a2 突变中正常触发；单种子稀疏漂移下三模式指标一致
  （突变末段 0.169、渐变末段 1.306），密集漂移场景恢复更快。
- `python scripts/run_pipeline.py --drift sudden`：末段 0.169，劣于基线 3/27 批；
  `--drift gradual`：末段 1.308，劣于基线 0/27 批。

## S2.1 超参数选择（2026-11-04，AutoHPO-Lite 8 候选网格搜索）

| 项目 | 说明 |
|------|------|
| 搜索空间 | 2 隐藏层 × 2 lr × 2 alpha = 8 组（任务书上限，超出报 ValueError） |
| 验证方式 | 时间隔离切分：train 前 70%、val 后 30%，`max(train_index) < min(val_index)`，无未来泄漏 |
| 成本记账 | 每次拟合如实计为 1 次训练，记录 CPU/墙钟耗时，不把试训伪装成一次 |
| 与在线管线解耦 | HPO 只在开发数据上跑一次，正式流仍用验证过的单一配置 |

HPO 结果（`python scripts/verify_hpo.py`，6 流 × 8 候选 = 48 次训练，墙钟 ~30s）：

| 排名 | 隐藏层 | lr | alpha | 均值 val RMSE |
|------|--------|-----|-------|--------------|
| 1 | (64,32) | 0.01 | **0.001** | 0.1556 |
| 2 | (32,16) | 0.01 | 0.001 | 0.1578 |
| 3 | (32,16) | 0.01 | 0.0001 | 0.1585 |
| 4 | (64,32) | 0.01 | 0.0001 | 0.1602（旧默认） |

最优配置 `(64,32)/lr0.01/alpha0.001`，已设为默认。lr=0.01 全面优于 0.001；
alpha=0.001 相对旧默认 0.0001 末段 val RMSE 提升约 2.9%。

## v2.0 改进版（官方公开集到手后启用）

思路迁移自光学装调技术（灵敏度矩阵 + 逆向优化）：

1. **动作反事实标定**：`python scripts/calibrate_actions.py` —— 对每个漂移场景把
   observe / incremental / full 三种动作各强制跑一遍，记录"决策点证据向量
   (residual_term, psi_term, mmd_term) → 该动作实测收益（末段 RMSE、标注消耗）"，
   生成 `runs/action_calibration.json`。
2. **代价敏感决策**：`config.json` 改 `"decision": {"mode": "cost_sensitive", ...}`，
   `src/decision.py::CostSensitiveDetector` 在线对每个动作做 k 近邻查表，取
   `argmin(预测RMSE + cost_label × 标注)`；查询点离标定表太远或表缺失时
   **自动回退 v1.0 阈值规则**。
3. 与 v1.0 的关系：v1.0 回答"漂移有多严重"，v2.0 回答"做哪个动作划算"。
   决策层替换、检测层不变，回滚保护等底线机制全部保留。

已知边界（答辩如实说明）：
- 合成 dry-run 的标定行是**流级**归因（末段 RMSE/标注挂在整条流上），官方公开集
  有分段真实漂移后应重标为段级归因；
- 代价权重暂不含剩余槽位/预算的实时状态（槽位感知决策留作后续）；
- 合成流上收益差异已无空间（五组 tier_bounds 的 J 最多差 2%），v2.0 的真实增益
  **必须在官方公开集上标定后才能声称**。

## 备用预案（按条件开启，互不依赖）

| # | 预案 | 触发条件 | 切换方法 |
|---|------|---------|---------|
| ① | tier_bounds 分档边界反解 | 官方公开集到手 | 按"精度+标注成本"双目标网格搜索（做法同 `scripts/calibrate_actions.py` 的 J 指标），把最优边界写进 `config.json.detector.tier_bounds` |
| ② | psi_top_k 敏感特征筛选 | 官方预提取特征为**高维**（几十维以上） | `config.json.detector.psi_top_k` 设为 3~5；10 维合成特征实测无收益，低维保持 0 |
| ③ | 按漂移类型分档 | 真实流上**幅度分档失灵**（如温和漂移持续被判 full/observe） | 退化为"域偏移→incremental、残差恶化→full"的二元规则，阈值线仍由 tier_bounds 控制 |

## 答辩口径（一句话）

现行版保证任何数据下能跑完且不低于静态基线；改进版把分档升级为
**带预算约束的决策问题**，数据一到就能标定；备用预案覆盖高维特征与
幅度分档失灵两种风险。
