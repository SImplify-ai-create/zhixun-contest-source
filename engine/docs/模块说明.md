# 模块说明（不用看代码也能读懂）

本项目是一个给工业模型用的"自动体检 + 自动进修"系统：发现数据规律变了 → 判断变多严重 → 决定学不学、学多深 → 验收 → 不合格自动退回，全程受"重训次数"和"标注条数"两个预算约束。

## 一、核心模块（src/）

| 文件 | 作用 | 对应 |
|---|---|---|
| `data.py` | 造数据：生成一整套工业传感器读数，并让规律在中途变掉。突变=某一步突然变；渐变=一节一节慢慢变 | 实验基础 |
| `dataset.py` | 接数据：合成数据、官方数据包（npz/npy/csv）、生产数据流统一成同一种格式 | 通用能力 |
| `drift.py` | 看病：判断数据变没变、变多严重。同时看两件事——数据整体分布偏没偏（自校准 MMD²）、单个数值的分布偏没偏（KS），两路都报警才算数；再把严重度换算成连续分数（残差倍数与 PSI 取大，输入侧证据封顶） | 创新点 1 + 2 前半 |
| `pipeline.py` | 决策与执行：按严重度决定"不学 / 补课 / 重学"，真的去训练、验收、不合格退回旧模型；同时管住重训次数和标注条数 | 创新点 2 + 3 |
| `advanced.py` | 两个省钱技巧：①预算不在前几次花光，只剩最后一次机会才限额 ②漂移正猛时只取最新一小段数据，避免新旧混合 | 创新点 4 + 5 |
| `cleaning.py` | 挑样本：重学之前剔除明显过时的旧样本，避免新旧知识打架 | 创新点 3 |
| `model.py` | 学习的人：基础回归模型，能从头学、能补课学、能打分 | 通用 |
| `config.py` | 读配置：把 config.json 和环境变量读成程序参数 | 通用 |
| `logger.py` | 记账：每一步写本地 CSV，可选同步 SwanLab 云端 | 通用 |
| `__init__.py` | 把以上模块打包，外部一次调用即可 | 通用 |

## 二、实验脚本（scripts/）

| 脚本 | 作用 | 使用场景 |
|---|---|---|
| `run_pipeline.py` | 单跑一次，可选突变/渐变、合成/官方数据 | 日常验证、现场演示 |
| `run_all.py` | 一键全跑所有场景并汇总总报告 | 交材料前 |
| `ablation.py` | 拆零件测试：完整系统 vs 去掉创新点 1/2/3，看各自掉多少分 | 证明创新点有效 |
| `budget_sweep.py` | 预算扫描：把预算从宽松调到很紧，看系统在哪撑不住 | 证明省预算能力 |
| `innov45_eval.py` | 创新点 4/5 专项评估 | 补实验 |
| `track_explore.py` | 轨迹探索：记录每一步误差变化，用于调参与归因分析 | 调参期 |
| `tier_probe.py` | 分档探针：测严重度落在哪一档，验证三档是否分得开 | 分级机制验证 |
| `tier_actions.py` | 分档动作对比：三档各自动作跑一遍，比较效果与标注代价 | 分级机制验证 |

## 三、一次运行的完整流程

1. **准备**：读配置（重训次数、标注额度）、准备数据流。
2. **开机**：用前 3 批稳定数据训练初始模型，同时拍一张"基准照"——一把冻结的参考尺子加初始误差，后续所有比较以它为准。
3. **逐批滚动**：每来一批新数据做三件事
   - 让模型打分，看现在错多少；
   - 用永不更新的参考尺子量这批数据，判断结构与分布变没变；
   - 把多项指标合成一个严重度分数。
4. **决策**：分数低 → 只记录不动；中等 → 补课（少量训练并保留旧知识）；很高 → 清洗旧样本后重学。
5. **验收**：新模型必须在新数据上优于旧模型，变差自动撤销。
6. **记账**：全过程写入 `runs/`，汇总为峰值误差、末段误差、重训次数、标注消耗。

## 四、runs/ 输出物

| 文件 | 内容 |
|---|---|
| `report-*.png` | 误差曲线（可见漂移点与恢复过程）、漂移指标曲线、预算消耗曲线 |
| `*-summary.json` | 单次运行结论（末段误差、重训次数、标注用量） |
| `*-*.csv` | 每一步明细（批次、误差、是否报警、采取的动作） |
| `innov45_eval.csv` | 创新点 4/5 对照结果 |
| `budget_sweep.csv` | 不同预算档的表现 |
| `SUMMARY.md` | 全部实验汇总表 |

## 五、config.json 参数含义

| 参数 | 含义 |
|---|---|
| `source` / `drift_type` | 数据来源、漂移形态 |
| `batch_size` | 一次处理多少条（即多久体检一次） |
| `max_retrains` | 最多允许重训几次（当前 6） |
| `label_budget` | 总共可用的标注条数（当前 4000） |
| `residual_factor` | 误差超过正常水平的几倍算异常（当前 3 倍） |
| `mmd_z_threshold` | 整体分布偏离参考零分布多少个标准差算变了（当前 3.0，即 3σ） |
| `psi_drift_threshold` | 数值分布偏移超过多少算显著（当前 0.25，行业标准线） |
| `use_rate_window` | 是否启用自适应取数窗口（创新点 5） |
| `use_budget_pacing` / `pacing_trigger` | 是否启用预算节流及其触发方式（创新点 4） |

## 六、30 秒版介绍

> 这是给工业模型用的"自动体检 + 自动进修"系统。它不看模型自己报的错误率（那会被模型自身的适应能力掩盖），而是用一把永不更新的尺子量数据本身变没变。发现漂移后按严重程度决定"不学、补课还是重学"，并严格受重训次数和标注条数约束。每次学完都要验收，不合格自动退回旧版本。当前实测（3 个随机种子）：突变漂移末段误差 0.209（初始 0.168）；纯域偏移场景分档比"一律全量重训"少花约 30% 标注且误差更低（0.156 vs 0.172）；渐变漂移末段 1.395 仍是短板。

## 七、已知局限（评审需知）

- 严重度分档已能分开三档（纯域偏移→incremental、浅概念漂移→observe/incremental、深概念漂移→full），但收益不均：浅概念漂移场景以约 19% 标注节省换约 9% RMSE 退化；突变与深概念漂移的严重度天然落满档，与"恒全量"必然相同。
- 预算节流在宽松预算下与不节流等价，仅在最后一个重训槽位起保护作用。
- 突变漂移末段误差 0.209 略高于初始 0.168（单种子最好 0.145），尚未完全恢复；渐变漂移末段 1.395 明显偏高。
- 官方评测指标尚未公开，当前所有数字均为自建合成流实验结果。
