## 0. 结论先行

1. **C-MAPSS 已经跑通，且自进化方案在 4 个子集上全部优于两个对照臂。** 末 5 批 RMSE（越低越好）：

   | 子集 | A 静态基线 | B 周期重训(p=8) | C 自进化 | C/A | C 重训次数 | C 标签消耗 |
   |---|---:|---:|---:|---:|---:|---:|
   | FD001（1 工况） | 66.46 | 43.49 | **28.17** | **0.42** | 6 | 4000 |
   | FD002（6 工况） | 61.55 | 61.49 | **35.13** | **0.57** | 6 | 2340 |
   | FD003（1 工况/2 故障模式） | 291.84 | 371.17 | **24.48** | **0.08** | 6 | 3220 |
   | FD004（6 工况/2 故障模式） | 48.46 | 47.80 | **29.45** | **0.61** | 6 | 4000 |

   两条要如实写进结论的观察：① **盲周期重训会害人** —— FD003 上 B 比 A 还差 27%，说明"定期重训"不是安全默认；
   ② **绝对误差仍远高于文献**（FD001 文献 LSTM 约 12–15 循环），本方案特征是轻量的 48 维，
   比较的是**臂间相对优势**，不能拿去对标文献 SOTA。

2. **三套数据的角色不能平权**：C-MAPSS 是回归主线与第一批对外数字；气体传感器是"任务适配器抽象是否成立"的试金石
   （分类 + 强漂移 + 小样本）；XJTU-SY 是最后的振动特征工程，**数据包已到位但仍是分卷 rar、未解压**
   （见 §14.4；适配器与三臂脚本已写完，尚无非空数字）。

3. **必须新增一层任务适配器**，把"指标计算 / 留出验收判断 / 静态基线锚比较"三处从主循环里抽出来，
   否则分类任务无法接入。**不改任何现有函数签名**，新参数一律给默认值。

4. **气体传感器的漂移判据要用分类概率，不能用残差。** 已在 batch1 上做了 5 折留出标定：
   参考期熵 0.0348 ± 0.0087，据此给出 `熵 > 0.0522`（μ+2σ）与 `错误率 > 0.0533` 双阈值，
   **不是拍脑袋**（§4 有完整推导与逐批实测）。

5. **最大的口径风险不是数据，是切分权**：批次怎么切、漂移点在哪、训练/测试怎么分，现在全由我们定义。
   若评测方重新切分，所有阈值都要重标定。因此切分方案必须**外置成清单文件 + 固定种子 + 可导出**（§10 风险 R2）。

## 1. 三个数据集的角色分工与优先级

| 优先级 | 数据集 | 承担什么验证职责 | 为什么是它 |
|---|---|---|---|
| **P0** | NASA C-MAPSS | ① 回归主线能否在真实工业退化流上成立 ② 漂移检测在"无人工注入漂移"的自然退化下是否还有意义 ③ 三臂对照的第一批对外数字 | 真实 run-to-failure 退化、样本量大（2 万~6 万行）、纯数值回归、无缺失、许可证最宽松；**唯一能在 1 天内跑出完整三臂的** |
| **P1** | UCI 气体传感器 | ① 任务适配器抽象成立性（回归→分类不改主循环）② 强漂移下的检测灵敏度 ③ 小样本 + 类别缺失的鲁棒性 | 10 个批次天然构成时间序列，**漂移是真实的传感器老化**，且 batch3/4/5 整类缺失是天然的"灾难漂移"用例 |
| **P2** | XJTU-SY 轴承 | ① 高频振动特征工程链路 ② 全寿命到失效的极长序列（单轴承上千个采样文件） | 特征提取最重（时域/频域/包络谱），单轴承原始数据即数 GB，放在最后不阻塞前两个交付节点 |

这三件事不解决就去碰分类和振动，会在两个新维度上同时踩坑，定位成本翻倍。

## 2. 三个数据集的批次构造方案

现有管线对"流"的要求（`SelfEvolutionPipeline.run`）：连续的 `(offset, X, y)`，`X` 二维、`y` 一维，
逐批推进、不可回退，每批默认 200 条，内部有窗口（默认 600）与重训槽位。

### 2.1 C-MAPSS：按"代"（cycle 对齐）切，不按 unit 切

**为什么不能按 unit 切**：单元寿命 128~543 循环（FD001），长短差 4.2 倍。若一个 unit 一批，
则每批的退化阶段构成完全不同（有的在第 10% 寿命，有的在第 90%），批与批的 RMSE 不可比，
"漂移"会变成"换了个发动机"这种伪信号。

**采用的构造（已实现于 `src/real_stream.py::CMAPSSStream`）**：

1. 把所有 train 单元按 `cycle` 对齐成**共同时钟**：第 e 代 = 所有在役单元在第 e 个循环的传感器读数。
2. **把代截断到最短寿命**（FD001 = 128），保证每一代都有全部单元参与 → 批内机队构成恒定。
   > 实测：不截断（跑到最长寿命 362）时末段只剩个位数单元，C 臂末 5 批 RMSE 从 52 恶化到 146，
   > 纯粹是尾部外推噪声。这个取舍写进代码注释。
3. 每 200 行合成一批（FD001 = 64 批，FD002 = 167 批）。
4. 目标 `y = min(life - cycle, 125)`，RUL 截断上限 125 是工业惯例，避免早期寿命段标签无信息量。
5. 特征 = 24 列原始量（3 操作设定 + 21 传感器）+ 24 列 5 代滚动均值 = **48 维**；
   标准化统计量**只在初始化窗口（前 3 批 = 600 行）上拟合并冻结**，之后不再更新。
   > 这是关键：如果做全局标准化，后段的协变量漂移会被抹平，漂移检测变成假命题。

**漂移点在哪**：C-MAPSS **没有人工注入的漂移点**。本流的"漂移"来自两处真实机制：
① 退化进度推进（协变量漂移，`P(X)` 变、`P(Y|X)` 不变）；
② FD002/FD004 的 6 种操作条件切换（协变量漂移 + 量纲跳变）。
**必须在对外材料里写清楚这不是"突变概念漂移"**，否则会被质疑"你的漂移点是造的"。

**时间不可逆怎么保证**：代的推进方向唯一，`batches()` 只按 offset 升序产出，管线不回看未来；
标准化只用前 600 行。**唯一的信息泄漏风险在留出验收集**——见 §8。

### 2.2 气体传感器：10 个 batch 天然对齐，直接用

- 一批 = 一个物理批次（`batch1.dat` … `batch10.dat`），样本数 161~3613 不等。
  批大小不固定，故 `batch_size` 参数对它无效，需要 `FixedBatchStream`（每个文件 = 一批）。
- **漂移点位置是已知的**：批次号即时间轴，传感器老化导致的漂移在 batch3 之后显著。
- 训练/参考期 = batch1（唯一"传感器状态最干净"的批次），之后 batch2~10 全部算部署期。
- 类别 6 在 batch3/4/5 完全缺失 → 这不做修正，**保留为真实灾难性漂移**，但要单独报告"类 6 的召回在 batch3~5 无定义"。

### 2.3 XJTU-SY：一行 = 一个 csv，一批 = 连续 N 个 csv

- 原始结构：`Bearing{1_1..1_5, 2_1..2_5, 3_1..3_5}/` 每目录上百至两千多个 CSV，**每个 CSV = 一次 1.28 s 采样**
  （采样率 25.6 kHz，32768 点/通道，2 通道：水平 + 垂直）。
- **一行 = 一个 csv 的特征向量**（2 通道 × 20 维 = 40 维实测特征，拼接 5 点滑动平均后 80 维）；
  **一批 = 连续 `--batch-files` 个 csv（默认 50）**。原计划"20 个 csv 取平均成一行、200 行一批"
  已废弃：那样单轴承只剩十几行，漂移检测的 MMD²（配 KS）与选择性清洗里马氏距离的
  样本排序在 n<30 时都不可信。**两者分工不同**：漂移检测只用 MMD² + KS，马氏距离
  只用于清洗阶段给历史样本排序，不参与任何报警判定。
- 工况 1/2/3 分别建模（转速与载荷不同，量纲不可混），跨工况不合并。
- **没有"已知早期故障起始点"文件**：官方只给了失效时刻判据（最大幅值 > 10×Ah 即判失效并立刻停机），
  所以漂移点只能由数据自己给（`drift_points` 为空，与 C-MAPSS 一致：无人工注入漂移）。

## 3. 任务无关化改造：任务适配器（核心）

### 3.1 现状问题

`src/pipeline.py` 中 `model.evaluate(X, y)["rmse"]` 直接出现在 **20+ 处**，且语义被硬编码为
"越小越好"：`new/old > 1.2` 触发回滚、`> baseline*2.0` 拒绝、`+5%` 静态锚、`rel_gain` 门槛、
PSI/残差趋势判断。分类任务的 macro-F1 是"越大越好"，直接塞进去会把所有比较方向搞反。

### 3.2 设计：`src/task_adapter.py`

**核心思想**：把每个任务映射成一个**统一的"损失标量"（越小越好）**，主循环只认这个标量；
对外报告时再用任务自己的指标字典。

```python
class TaskAdapter:
    name: str
    def fit_target(self, y_raw) -> y_model      # 标签变换（如分类→整数编码）
    def loss(self, y_true, y_pred, proba=None) -> float   # 统一损失，越小越好
    def metrics(self, y_true, y_pred, proba=None) -> dict # 对外指标
    def format_pred(self, pred_raw) -> np.ndarray         # 输出格式化

class RegressionAdapter(TaskAdapter):
    # loss = RMSE（与现状完全一致，保证旧数字不变）
    # metrics = {rmse, mae, r2}

class ClassificationAdapter(TaskAdapter):
    # loss = 1 - macro_F1
    # metrics = {accuracy, macro_f1, per_class_f1, confusion_matrix, mean_conf, entropy}
```

**三处接入点（这就是用户要求抽出来的三件事）**：

| 接入点 | 现状代码 | 改造后 |
|---|---|---|
| ① 指标计算 | `self.model.evaluate(X, y)["rmse"]` ×20+ | `self._loss(X, y)` → `self.task.loss(y, self.model.predict(X), proba)` |
| ② 留出验收判断 | `_accept_split` 里的 `cand_rmse <= inc_rmse` | 复用同一个 `loss`，"越小越好"语义天然成立，无需改判断逻辑 |
| ③ 静态基线锚 | `cand > anchor * (1 + static_margin)` | 同上；分类下 = `cand_loss > anchor_loss*(1.05)`，即 macro-F1 掉超过约 5 个百分点触发拒绝 |

**兼容性保证**：
- `SelfEvolutionPipeline.__init__(..., task=None)`，`task=None` → `RegressionAdapter()`，**旧 config 与旧脚本零改动**。
- `model.evaluate()` 保留原样不动（外部脚本仍可调用），只是主循环不再依赖它的 `["rmse"]` 键。
- 回归分支的 `loss` 定义与 RMSE 逐位相同 → **C-MAPSS 与所有历史合成流数字保持可比**。

### 3.3 分类模型（`src/model.py` 新增 `ClassifierModel`）

- 实现同一套 `fit / predict / predict_proba / evaluate` 接口，内部用 `MLPClassifier`（sklearn，不引入 torch）。
- 清洗不依赖训练侧权重：分类与回归同一实现，按马氏距离排序后保留前 `keep_ratio` 比例的
  历史行（`X_hist[keep_idx]`），其余行直接丢弃。
- **不做的**：不引入深度学习框架、不做类别重采样（class_weight 走 `MLPClassifier(class_weight=...)` 可选，
  默认 `None`，避免改变既有行为）。

## 4. 气体传感器的漂移判据（分类专用，双路融合）

### 4.1 为什么不能沿用残差

回归下"残差上升 = 漂移"。分类下没有残差，等价物有三类：**错误率、置信度、预测熵**。
单看错误率会漏"高置信度全错"（模型自信地崩），单看熵会漏"低置信但恰好蒙对"。故三条都用。

### 4.2 判据公式

设第 t 批的预测概率矩阵为 `P_t ∈ R^{n×6}`：

```
置信度   conf_t = mean_i max_c P_t[i,c]
熵       H_t    = mean_i ( - Σ_c P_t[i,c] · log P_t[i,c] )
错误率   err_t  = 1 - accuracy_t
```

**参考期标定（batch1，5 折分层留出，非训练自评）**：

| 统计量 | 均值 μ | 标准差 σ | 阈值（μ+2σ 或 1-(μ-2σ)） |
|---|---:|---:|---:|
| 熵 H | 0.0348 | 0.0087 | **0.0522** |
| 错误率 err | 0.0202 | 0.0165 | **0.0533** |
| 置信度 conf | 0.9896 | 0.0046 | **0.9804**（下限） |

**判定（与输入侧双路融合）**：

```
S_cls(t) = max( H_t / 0.0522 , err_t / 0.0533 )          # 输出侧证据强度
S_in(t)  = 现有 MMD² 的 z 分数（输入侧，Bonferroni 校正后的 KS 亦是）
漂移成立  ⟺  S_cls(t) > 1  AND  S_in(t) > 3
```

三档严重度仍沿用 `max(残差倍数, PSI)` 的形状，把"残差倍数"替换为 `S_cls`：

```
severity(t) = max( S_cls(t), PSI_effect )      # <1.0 observe / 1.0–3.0 incremental / ≥3.0 full
```

**为什么必须"与"而不是"或"**：气体数据 batch3/4/5 整类缺失，输出侧一定爆表；
但若输入侧 MMD 也同步升高，才是真漂移；只靠输出侧会把"模型本来就没学好类 6"当成漂移。

### 4.3 实测证据（batch1 训练，逐批推理）

|---:|---:|---:|---:|---:|---|

| 2 | 1244 | 0.857 | 0.651 | 0.085 | ✅ 漂移 |

## 5. C-MAPSS 工况归一化（FD002 / FD004 必需）

**问题**：FD002 有 6 种操作条件（高度/马赫数/油门），同一台发动机在不同条件下的传感器读数
量纲差一个数量级。不做处理时，每一次工况切换都会被 MMD² 判成漂移 → 全程误报，
重训槽位在头 20 批就被烧光。

**做法（两步，默认全开）**：

1. **工况聚类**：对 3 个 setting 列做 `KMeans(k=6)`（种子固定 42）得到条件标签。
   > 不能用 `np.unique(np.round(x, 2))`：实测会得到 11 个伪簇（setting 列自带测量噪声）；
   > 1 位小数也是 7 簇。**必须显式聚类。**
2. **按条件分位数归一化**：对每个条件 c，把 21 个传感器分别映射到该条件内的经验分位数（0~1）。
   等价于"条件内 rank 归一化"，对非高斯、非平稳的传感器分布比 z-score 稳。
   实现：`sklearn.preprocessing.QuantileTransformer(n_quantiles=1000, output_distribution='uniform')`，
   **每个条件单独 fit，且只用初始化窗口内的样本 fit**（避免未来信息泄漏）。

**对"漂移"定义的影响（必须在对外材料写明）**：
- 归一化**抹掉**的是"工况切换"这一类协变量漂移 —— 它是**已知的、可解释的、不需要重训的**。
- 归一化**剩下**的才是真正的退化漂移（`P(Y|X)` 随磨损变化）+ 未见工况的残余偏移。
- 结论：**归一化后检测到并触发重训的，才是"值得花预算"的漂移**。这是把误报压下去的正道，
  不是"掩盖问题"。
- 副作用：FD001/FD003 只有 1 个条件，`KMeans(k=1)` 退化为恒等，归一化仍生效。

## 6. 标注预算口径重定义

**问题**：离线回放里标签本应免费（历史数据都有 y），现有 4000 标签预算失去成本含义。
但这不意味着预算机制作废——**重训次数限制才是真成本**，标注预算要换个有物理意义的定义。

**新口径（"新购标签"模型）**：

> 预算 = 为适配新工况/新单元而**必须新增人工标注**的样本条数。
> 历史批次里已有的标签是"沉没成本"，不重复计费；只有进入训练窗口、且此前从未被标注过的样本才扣预算。

具体记账规则（在 C-MAPSS 上）：

| 场景 | 是否扣预算 | 理由 |
|---|---|---|
| 初始化窗口（前 3 批 600 条） | ✅ 扣 | 冷启动必须有人标 |
| 重训时复用历史窗口内已标注样本 | ❌ 不扣 | 已付过费 |
| 重训时纳入**新批次**的样本 | ✅ 按新增条数扣 | 这些是新数据 |
| 留出验收集的标签 | ❌ 不扣 | 验收用的是已标注样本的子集（`eval_labels_free=True` 已实现） |
| KF 的 `track()` 在线更新 | ⚠️ 单独记账，不进主预算 | 现状如此，必须显式披露（见风险 R5） |

**会因此失效的历史数字**（必须在替换时逐条标注"旧口径"）：
- README「已验证结果」表里的**标注消耗**列（1833 / 1820 / 960 / 840）；
- 所有 `budget_sweep` 类实验的"预算档位"结论（tight/medium/loose 的绝对量不可比）；
- 分析报告 `analysis_20261105` 中所有以 `labels_used` 为横轴的结论。

## 8. 验收指标与对照臂

### 8.1 三臂定义（三个数据集统一，已实现于 C-MAPSS）

| 臂 | 定义 | 作用 |
|---|---|---|
| **A 静态基线** | 初始化窗口训练一次，永不更新 | 下界，证明"不重训会烂成什么样" |
| **B 周期重训** | 每 8 批用最近 600 条标签全量重训 | 上界的"朴素做法"，证明"盲重训不是免费午餐" |
| **C 自进化** | 现有闭环（检测→分级→清洗→留出验收→静态锚） | 待验证方案 |

三臂必须共享：同一数据顺序、同一模型类、同一批大小、同一初始化窗口、同一评估口径（**先预测后适应**）。

### 8.2 主指标

| 数据集 | 主指标 | 辅指标 |
|---|---|---|
| C-MAPSS | 末 5 批 RMSE（越低越好） | 峰值 RMSE、重训次数、新购标签条数、逐批曲线 |
| 气体传感器 | 末 3 批 macro-F1 | accuracy、per-class F1、混淆矩阵、熵曲线 |
| XJTU-SY | 末 5 批 RMSE（剩余寿命占比回归，标签需事后可知 N，见 §14.2） | 同上 |

### 8.3 判"成功"的门槛（先定门槛再看数，避免事后调标准）

1. **主门槛**：C 的末段主指标**优于 A 与 B 两者**，且优势 > 各自批间标准差。
2. **成本门槛**：C 的新购标签 ≤ B 的 80%，重训次数 ≤ B。
3. **不退化门槛**：**留出验收闸门与静态基线锚保持默认开启**，不允许为了跑分关掉（这是 v1.1 的合规底线）。
4. **诚实门槛**：若 C 在任一数据集上不赢，**就写"无优势"**，并在报告里给出原因分析（不允许换指标救场）。

### 8.4 C-MAPSS 已达成情况

| 子集 | 门槛 1（优于 A、B） | 门槛 2（成本） | 结论 |
|---|---|---|---|
| FD001 | ✅ 28.17 < 43.49 < 66.46 | ⚠️ 标签 4000 = B 的 111%，重训 6 = B 的 6 | 精度赢、成本没赢 |
| FD002 | ✅ 35.13 < 61.49 | ✅ 标签 2340（B 的 65%），重训 6 | 双赢 |
| FD003 | ✅ 24.48 ≪ 291.84；B 反而比 A 差 | ✅ 标签 3220（B 的 89%） | 双赢 |
| FD004 | ✅ 29.45 < 47.80 | ⚠️ 标签 4000（B 的 111%） | 精度赢、成本没赢 |

**如实结论**：C-MAPSS 上"精度全面占优"成立；"成本也占优"只在 2/4 子集成立，
另外 2 个把预算花满了。原因待查（疑似 `full` 档清洗后重训吃光预算），列入下一步。

## 13. 实测结果登记（滚动更新）

> 每一节都是**已经跑出来的数**，命令在文末附录。臂定义统一：
> A=静态基线（只初始训练一次，永不更新）、B=周期重训、C=现有自进化方案。
> 三臂共享同一数据顺序、同一批大小、同一初始化窗口、同一 prequential（先预测后适应）口径。

### 13.1 C-MAPSS（回归，主指标 RMSE，末 5 批）

| 子集 | A 静态 | B 周期(p=8) | C 自进化 | C/静态 | C 重训次数 | C 标签消耗 |
|---|---|---|---|---|---|---|
| FD001（单工况） | 66.456 | 43.488 | **28.174** | 0.424 | 6 | 4000（预算打满） |
| FD002（6 工况） | 61.553 | 61.486 | **35.130** | 0.571 | 5 | 2340 |
| FD003（双故障模式） | 291.841 | 371.165 | **24.477** | 0.084 | 5 | 3220 |
| FD004（6 工况×双故障） | 48.458 | 47.796 | **29.452** | 0.608 | 6 | 4000（预算打满） |

结论（守住三条边界）：
1. **只主张同数据同预算下的臂间相对优势**，不主张 SOTA；绝对误差远高于文献，不做横向比较。
2. **成本没有全赢**：FD001/FD004 上 C 把 4000 标签预算花满，是 B 的 111%（4000/3600）；省标注只在 FD002/FD003 成立。
3. FD003 上 B 比 A 差 27%（371.165 vs 291.841）是**核心证据**，但归因必须写清：盲周期重训 + 该子集双故障模式 + 末段机队构成特殊，**不能泛化成"周期重训一定更差"**。

### 13.2 UCI 气体传感器阵列漂移（分类，主指标 macro-F1，末 3 批）

阈值标定（仅用 batch1 稳定批，5 折分层留出，均值 ± 2σ）：
留出 macro-F1 = 0.9671 ± 0.0223；`熵 > 0.0434`、`错误率 > 0.0449`、`置信度 < 0.9830` 判报警。

| 臂 | 末 3 批 macro-F1 | 末 3 批 accuracy | 最低批 F1 | 重训次数 | 标签消耗 |
|---|---|---|---|---|---|
| A 静态 | 0.233 | 0.319 | 0.157 | 1 | 445 |
| B 周期(p=2) | 0.388 | 0.455 | 0.091 | 5 | 2845 |
| C 自进化（`fuse=or`，含 D6 修复） | **0.467** | **0.496** | 0.182 | 4 | **2301** |

- 末批（batch10）C 臂 per-class F1：Ethanol 0.615 / Ethylene 0.564 / Ammonia 0.749 /
  Acetaldehyde 0.710 / Acetone 0.925 / Toluene 0.851；混淆矩阵见 `runs/gas_d6_d5_all.txt`。
- **诚实结论**：末 3 批 C 仍占优（0.467 vs 0.388 vs 0.233），但**不是每批都赢**：
  batch8（294 条）C 只有 0.182，小批窗口重训后的恢复不稳定，不掩盖。

### 13.3 阴性对照（"应当不报警"）与三个必须记住的发现

阴性对照（默认决策：同批随机留出，因为 UCI 没有第三个"已知无漂移"时段）：

| 训练量 | 次数 | 分类侧误报 | 输入侧误报 | OR 融合 | AND 融合 |
|---|---|---|---|---|---|
| 80%（≈部署量级） | 5 | 0/5 | 0/5 | 0/5 | 0/5 |
| 50%（小样本压力） | 5 | **5/5** | 0/5 | 5/5 | **0/5** |

判据分两句写，不能合并：
- **检测灵敏度已验证**：batch2~10 共 9 批，输入侧（MMD²/KS）与分类侧（熵/置信度/错误率）均 9/9 报警。
- **误报率只在"训练量≈部署量级"下验证通过（0/5）**；训练量减半时分类侧误报 5/5，
  说明阈值对训练样本量敏感。**不得对外宣称"误报率已验证"**，只能写"80% 训练量下未观察到误报，
  阈值对训练量敏感，跨工况误报率仍待验证"。

时序前后半段切分仅作诊断：UCI 的 `.dat` 文件**按类别排序**，前半段缺类，
训练必然崩（错率 0.79~0.84），不构成有效零分布，不计入误报率。

**F1（已按拍板修复，见 13.5）**：C 臂每次重训 `kept_hist = 0`——概念漂移档 `keep_ratio=0.0`
把历史全部丢弃，只用当前窗口。batch4 只有 161 条且缺类别 6，重训后下一批 macro-F1 掉到 0.229
（低于不重训的 0.268）。同时该次"留出验收"显示 new_loss=0.000（同批自洽），说明
**小批 + 缺类会让留出验收失去判别力**。修复方式：不做"按类补样"（要额外买标注），
改为 ① 历史类别缓冲（每类 20 条、新增标注 0）+ ② 验收有效性闸门。

- **默认 `or`，不改**：单工况下精度最稳（FD001 28.174 vs perf_only 33.091，9 个百分点

- **`and` 停用**：四个场景无一胜出（FD001 41.388、FD002 无额外收益、气体退化为性能侧），

- **可追溯**：模式写入 `config.json` 的 `pipeline.task_fuse` 与实验记录每行的 `task_fuse` 字段，

### 14.2 标签定义（本数据集最大的风险点，不含糊）

官方**没有任何逐点标签**。由于试验在"最大幅值 > 10×A_h"时立即终止，**最后一个 csv 就是失效时刻**，
N 即全寿命采集次数。据此把标签构造成**剩余寿命**（与 C-MAPSS 的 RUL 同源），两种刻度：

| 口径 | 公式 | 取值范围 | 用途 |
|---|---|---|---|
| `rul_ratio`（**默认**） | `y = (N − 1 − i) / (N − 1)`，i 从 0 起 | 1.0 → 0.0 | 主指标。无量纲，15 个轴承可直接平均 |
| `rul_min` | `y = (N − 1 − i) × 1 min` | 41 → 0 min（以 2_4 为例） | 辅助口径，给工程读者看"还剩几分钟" |

**为什么用比例而不是绝对分钟**：15 个轴承的实际寿命差 60 倍（42 min ~ 42 h18min）。绝对 RUL 的
RMSE 会被 3_1/3_2 这类长寿命轴承主导，短寿命轴承的误差在平均值里几乎不可见；比例口径下每个
轴承对均值的贡献相当。缺点是与 C-MAPSS 的"分钟/循环"绝对值不可直接比较，只能比**相对改善倍数**。

**三条必须在论文/答辩中写明的局限**：

1. **标签需要知道 N（失效时刻）才能构造 → 只有离线回放可得，线上不可得**。特征 X 里没有任何
   未来信息（不构成特征泄漏），但这是"事后口径"，**不能对外宣称成在线 RUL 预测**。
   线上可用的只有"退化程度估计 + 漂移报警"，不是 RUL。
2. **单轴承时序切分下，模型拟合的是一条退化轨迹本身的形状，不是跨个体泛化**。只有 15 条轨迹，
   跨轴承泛化要留一轴承（LOBO）验证，样本量不足，本轮不做，也不报这个数字。
3. **1_5 / 2_4 / 3_2 属于"突然失效型"**（失效位置含保持架/滚动体，或寿命极短如 42 min），
   失效前信号无可见前兆。任何基于振动统计量的模型在末尾几批都不可能预测准，
   会造成"末 5 批 RMSE 难看"。这是数据性质，不是方法缺陷，但必须在结果表里点名。

**为什么标签是单调递减的（必须写进讨论）**：这使"静态模型"天然处于劣势 —— 只见过早期数据
（y≈0.6~1.0）的模型必须向下外推到 0，而无界 MLP 在 ReLU 区域外会给出远小于 0 的预测。
因此三臂统一把预测**裁剪到标签值域**（`rul_ratio` 裁到 [0,1]，`rul_min` 裁到 [0, N−1]），
对三臂完全一致。不裁剪的话实测量级会到 RMSE 3.6（标签本身只有 0~1），指标失去意义。
裁剪后 A/B/C 的排序结论不变，但 RMSE 可解释。**已拍板保留该处理**：所有引用这批数字的
表格/图注/讲稿必须显式标注「预测值已裁剪至标签值域」，不得让读者误认为是模型原始输出。
