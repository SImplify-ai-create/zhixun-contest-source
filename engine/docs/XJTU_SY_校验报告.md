## 4. 9217 与 9216 的差额

压缩包条目清单（`7z l`）：**9236 条 = 9217 文件 + 19 目录**。
- 9217 文件 = **9216 个 `*.csv` + 1 个 `Introduction_to_XJTU-SY_Bearing_Dataset.pdf`**
- 19 目录 = 1 根 + 3 工况 + 15 轴承
- 条目名**无重复**、无非法字符、无隐藏文件；解压结果与条目清单 1:1 吻合

结论：多出来的 1 个文件就是那份 PDF，不是丢数据也不是多数据。

## 5. 那 1 条 7z warning

原始解压日志未落盘，无法回溯原文；改用可复现方式——对分卷做只读 CRC 测试
（`7z t`，**不重新解压**），warning 稳定复现：

```text
WARNINGS: There are data after the end of archive
Path = ...\XJTU-SY_Bearing_Datasets.part01.rar
Type = Rar5 ; Physical Size = 744482177 ; Tail Size = 6783
Total Physical Size = 4444566778 ; Volumes = 6
Everything is Ok
Archives with Warnings: 1 / Warnings: 1
Folders: 19 / Files: 9217 / Size: 12220812451
```

- 含义：part01.rar 末尾多出 **6783 字节**尾部数据。744,482,177 + 6,783 = 744,488,960 = 该分卷在磁盘上的实际大小，
  属下载/传输残留，不是压缩内容的一部分。
- 影响：**无**。CRC 全量校验 `Everything is Ok`，9217 文件 / 19 目录 / 12,220,812,451 B 与磁盘解压结果逐项吻合；
  尾部数据被忽略、不参与解压。
- 处理：忽略该 warning，不重解压，**原始分卷保留未删除**。

复现：

```powershell
& "C:\Program Files\7-Zip\7z.exe" t "real_data/XJTU-SY_Bearing_Datasets\Data\XJTU-SY_Bearing_Datasets.part01.rar"
```
